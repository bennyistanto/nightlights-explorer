<div class="notice">
  <p><strong>What this page can and cannot say.</strong> Nothing here has been checked against records of power or damage. Cloud hid Palu on most nights, the control cities are hundreds of kilometres away and seen from other angles, and only the part of the affected area south of the equator and west of 120 E is covered. The figures against a similar viewing angle rest on two or three reference nights, too few to test that method here. The page says how much light was seen. It does not say why a place was dark, and nothing here is a statement about electricity.</p>

```js
import {files as lombokFiles} from "./data/events/lombok2018/files.js";
import {files as national} from "./data/files.js";
import {loadTyped} from "./components/load.js";
```

```js
const meta = await files["meta.json"].json();
const lombok = await lombokFiles["meta.json"].json();
const S = meta.story, F = S.focus, C = S.control, R = S.recovery;
const cells = await loadTyped("palu-cells", files["cells.u32.gz"], Uint32Array);
const raw = await loadTyped("palu-nights", files["nights.u8.gz"], Uint8Array);
const recovery = await loadTyped("palu-recovery", files["recovery.u8.gz"], Uint8Array);
const info = await loadTyped("palu-info", files["cell_info.u8.gz"], Uint8Array);
const D = meta.dates.length, N = cells.length;
const dates = meta.dates.map((s) => new Date(`${s}T00:00:00Z`));
const night = (iso) => meta.dates.indexOf(iso);
const K = night(meta.marks[0].date);
const provinces = await national["outlines/province.geojson"].json();
const districtOutlines = await national["outlines/district.geojson"].json();
const shown = districtOutlines.features.filter((f) => F.districts.includes(f.properties.code));
const COLS = 86400, DEG = 1 / 240;
const lon = Float32Array.from(cells, (i) => -180 + ((i % COLS) + 0.5) * DEG);
const lat = Float32Array.from(cells, (i) => 90 - (Math.floor(i / COLS) + 0.5) * DEG);
const day = (k, long = true) => dates[k].toLocaleDateString("en-GB", {day: "numeric", month: long ? "long" : "short", timeZone: "UTC"});
const pct = (v, digits = 0) => `${(100 * v).toFixed(digits)}%`;
const brbg = d3.schemeBrBG[7];
const CLASS_COLOURS = [null, NO_VALUE, NO_VALUE, brbg[0], brbg[1], brbg[3], brbg[5], NO_VALUE];
const rgb = (hex) => [1, 3, 5].map((k) => parseInt(hex.slice(k, k + 2), 16)).join(", ");
const FOCUS = {key: "palu", bounds: [[119.62, -1.22], [120.0, -0.6]]};
const outlines = shown.map((feature) => ({feature, id: null, state: null, weak: false, fill: "transparent", text: ""}));
const cellMap = (level, colours, sync = null) => (width) => drawMap({width, land: provinces.features, units: outlines, context: [], selected: [],
  lights: {lon, lat, level, colours: colours.map((c) => (c ? rgb(c) : null))}, focus: FOCUS, sync, onPick: () => {}});
const nightLevel = (k) => { const level = new Uint8Array(N); for (let i = 0; i < N; i++) level[i] = info[2 * i] === 1 ? raw[k * N + i] & 7 : 0; return level; };
const classLegend = html`<div class="legend">${[[3, "under 50% of its reference"], [4, "50 to 80%"], [5, "80 to 125%: about the same"], [6, "125% or more"]].map(([k, label]) =>
  html`<span class="legend-item"><span class="swatch" style=${`background:${CLASS_COLOURS[k]};`}></span>Cell at ${label}</span>`)}
  <span class="legend-item"><span class="swatch" style=${`background:${NO_VALUE};`}></span>Cell not seen that night (cloud or a poor-quality retrieval), which is not the same as dark</span></div>`;
// the nights on which enough of the area was seen to say something
const points = meta.dates.map((_, k) => ({k, date: dates[k], since: k - K, seen: F.raw.seen[k], raw: F.light[k], adjusted: F.light_adjusted[k]})).filter((p) => p.seen >= 30);
const at = (iso) => points.find((p) => p.k === night(iso));
const before = points.filter((p) => p.since < 0 && p.adjusted !== null);
const baseline = d3.median(before, (p) => p.adjusted);
const [beforeK, firstK, lateK] = [night("2018-09-22"), night("2018-10-01"), night("2018-10-24")];
const G = S.same_geometry, M = S.matched;
// against reference nights seen from within M.tolerance degrees of the same angle; a night needs 75 cells to be quoted
const like = (iso) => M.focus.light[night(iso)];
const later = d3.range(K + 13, D).filter((k) => M.focus.light[k] !== null && M.focus.cells[k] >= 75);
const show = (v) => (v === null || v === undefined ? "no figure" : pct(v));
// 22 September, 8 October and 24 October are sixteen nights apart: the same viewing angle
const chain = G.focus.ratio[night("2018-10-08")] * G.focus.ratio[night("2018-10-24")];
```

## Two nights later, a few percent on the few cells seen

<p>The night of the earthquake itself the satellite passed seven and a half hours after the shock and found the area at <span class="dyn">${pct(at("2018-09-28").raw)}</span> of its reference light. The next night was lost to cloud. On ${day(night("2018-09-30"))} only ${at("2018-09-30").seen} cells could be seen, and they gave <span class="dyn">${pct(at("2018-09-30").raw, 1)}</span>. On ${day(night("2018-10-01"))}, with ${at("2018-10-01").seen} cells seen, <span class="dyn">${pct(at("2018-10-01").raw)}</span>. These two figures rest on few cells, but they are far below anything else in the record, and far below what a change of viewing angle can do. Sixteen nights before the earthquake the satellite saw the area from the same angle as on the night itself: over the <span class="dyn">${G.focus.cells[K]}</span> cells seen on both, the light was <span class="dyn">${show(G.focus.ratio[K])}</span> of what it had been. Balikpapan, Samarinda and Makassar, measured the same way, gave <span class="dyn">${show(M.control.light[K])}</span> of their light at that angle.</p>

## Weeks, where Lombok took a night

<p>After Lombok's third earthquake the cells seen lost about half their light and had it back the next night. Palu was still far down three nights later, and well down ten nights later. The level of single nights cannot be trusted here: the same town reads tens of percent brighter or dimmer as the satellite's angle changes, and before the earthquake Palu already ranged from <span class="dyn">${pct(d3.min(points.filter((p) => p.since < 0), (p) => p.raw))}</span> to <span class="dyn">${pct(d3.max(points.filter((p) => p.since < 0), (p) => p.raw))}</span> of its reference. But every sixteenth night the angle repeats. Six nights before the earthquake, ten nights after and twenty-six nights after are such a set. Ten nights after, the cells seen on both nights gave <span class="dyn">${show(G.focus.ratio[night("2018-10-08")])}</span> of their light before the earthquake. Twenty-six nights after, about <span class="dyn">${show(chain)}</span>. A wider rule gives more nights: compare each cell with any reference night seen from within ${M.tolerance} degrees of the same angle. By that rule the area stood at <span class="dyn">${show(like("2018-09-28"))}</span> on the night of the earthquake, <span class="dyn">${show(like("2018-10-08"))}</span> ten nights after and <span class="dyn">${show(like("2018-10-24"))}</span> at twenty-six, with the nights from the thirteenth on ranging from <span class="dyn">${show(d3.min(later, (k) => M.focus.light[k]))}</span> to <span class="dyn">${show(d3.max(later, (k) => M.focus.light[k]))}</span> on whichever cells the cloud allowed. So on the two nights that can be compared at one angle the area stood at about six tenths and then about nine tenths. Each of those is a single night, and nothing in between is a clean curve.</p>

<p class="kicker">3 · Where the light came back, and where it did not</p>

## Where light was seen back

<p>For each cell that dimmed, count the nights until it was first seen back at <span class="dyn">${pct(R.back_ratio)}</span> of its level. Of the <span class="dyn">${R.hit.toLocaleString("en")}</span> cells that dimmed, <span class="dyn">${R.back_within["7"]}</span> ${R.back_within["7"] === 1 ? "was" : "were"} seen back within a week, <span class="dyn">${R.back_within["14"]}</span> within two weeks, <span class="dyn">${R.back_within["21"]}</span> within three and <span class="dyn">${R.back_within["30"]}</span> within thirty nights. <span class="dyn">${R.never_back}</span> had not been seen back when the record here ends, ${R.last_night} nights after. A cell can only be counted on a night it was seen, so the counts seen back are lower bounds and the nights are upper bounds. This count still divides by the distant control cities, and the rule that calls a cell dimmed also catches some cells on ordinary nights, so read the map for where light was seen back, not for exact dates.</p>


<p class="kicker">4 · What stayed invisible</p>

## Most nights, the satellite saw cloud

<p>This is the hardest of the four case studies to read, and the reasons belong on the page. The area was seen well on only a handful of nights. The epicentre is in this tile, 72 km north of the city, but the parts of Donggala and Parigi Moutong north of the equator are in another tile and are not here. No dark cell within 40 km of the epicentre became lit; the city lies outside that radius, so this says nothing about the city. And a cell that was never seen back cannot be told apart from one that was simply under cloud on every later night.</p>

Earthquake time, magnitude and epicentre: USGS catalogue, event us1000h3p4. A file dated D is the night that begins on the evening of local date D.</p>
